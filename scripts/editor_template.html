    Como usar

    Arraste uma mesa para movê-la. Ela fica vermelha enquanto estiver em cima de uma zona protegida, de um vão de porta, de outra mesa ou fora do salão.

    R gira a mesa selecionada 90°. As setas movem de um passo, com Shift de dez. Esc desmarca.

    Arraste o fundo para deslocar a planta; a roda do mouse aproxima e afasta.

    O que você mover fica salvo só neste navegador. Copiar posições leva as 28 coordenadas para a área de transferência.
